# Gemini Clone

A web application that functions as a **clone of the Google Gemini AI chatbot**. It provides a user-friendly interface for interacting with the Gemini model, allowing users to ask questions and receive intelligent, conversational responses.

---

## Features

- **Responsive Chat Interface** – Works smoothly across various screen sizes  
- **AI Integration** – Connects directly to the **Google Gemini API**  
- **Typing Animation** – Simulates realistic response typing  
- **Conversation History** – Stores past interactions for easy reference  
- **Custom Styling** – Modern and visually appealing user interface  

---

##  Technologies Used

- **Frontend:** React, HTML, CSS  
- **API:** Google Gemini API  

---

## Getting Started

### Prerequisites
Make sure you have the following installed:  
- [Node.js](https://nodejs.org/) and npm  
- A code editor (e.g., VS Code)  
- A **Google Gemini API key** from [Google AI Studio](https://aistudio.google.com/)  

---

### 🔧 Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Lakshmi-0301/Gemini-clone.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd Gemini-clone
   ```

3. **Install the required dependencies:**
   ```bash
   npm install
   ```

4. **Set up your API key:**
   - Create a file named `.env.local` in the main folder of your project.  
   - Add your Gemini API key to this file in the following format:  
     ```env
     VITE_GEMINI_API_KEY="YOUR_API_KEY"
     ```
   - Replace `"YOUR_API_KEY"` with the actual API key you obtained from **Google AI Studio**.

---

### Usage

1. **Start the development server:**
   ```bash
   npm run dev
   ```

2. **Open the application in your browser:**  
   The app will typically run at: [http://localhost:5173](http://localhost:5173)

3. **Interact with the AI:**  
   - Type your question or message into the input box  
   - The Gemini AI will respond in a conversational style  
   - Continue the conversation and explore different responses
